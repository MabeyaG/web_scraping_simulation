# Web Scraping Simulation

This project simulates a web scraping engine at scale, featuring rotating proxies, request queues, and dynamic data flow control. It's designed to handle large-scale scraping tasks efficiently and without overloading servers.

## Features
- **Rotating Proxies**: Simulates a real-world scraping environment using multiple proxy IPs.
- **Request Queues**: Manages a list of URLs to scrape in a queue, allowing efficient request handling.
- **Dynamic Data Flow Control**: Adds realistic delays and error handling to simulate a live scraping process.
